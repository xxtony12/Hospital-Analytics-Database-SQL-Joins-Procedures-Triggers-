# Hospital Operations & Billing Analytics Dashboard

## Project Overview
Developed a hospital operations and billing analytics solution integrating relational SQL database design with interactive Power BI dashboard reporting.

The project combines operational healthcare datasets, analytical SQL workflows, and business intelligence visualizations to support KPI reporting, billing analysis, healthcare utilization monitoring, and operational decision-making.

---
## Technologies Used
- SQL
- MySQL
- Power BI
- Relational Database Design
- Stored Procedures
- Triggers
- Data Visualization
- KPI Reporting
- Aggregation & Multi-table Joins

## Business Problem
Healthcare organizations rely on operational reporting and billing analytics to monitor financial performance, patient utilization trends, insurance activity, and operational efficiency.

This project demonstrates how SQL analytics workflows and Power BI dashboard reporting can support healthcare operational visibility and business decision-making.

---
## SQL Database Features
- Multi-table JOIN queries
- Aggregated billing analysis
- Date-range reporting stored procedure
- High-debt identification procedure
- Data validation trigger (age enforcement)
- Insurance normalization trigger

---


## Power BI Dashboard Features
- KPI scorecards for billing and admissions metrics
- Billing trend analysis over time
- Insurance provider billing comparisons
- Admission type distribution analysis
- Operational healthcare reporting visuals
- Interactive dashboard analytics

---

## Business Questions Answered
- Which insurance providers contribute the highest billing totals?
- How have billing trends changed over time?
- What percentage of admissions are emergency, urgent, or elective?
- Which patients accumulated high billing balances?
- How can operational reporting improve healthcare visibility and financial analysis?
